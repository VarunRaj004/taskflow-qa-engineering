# Reports

Generated, non-authored output lands here (and is produced by the commands documented in the
top-level README / `api-testing/README.md` / `automation/playwright/README.md`):

- `reports/newman/` — Newman CLI/HTML output from running the Postman collection
- `reports/playwright-html-report/` — Playwright's HTML report (open `index.html`)
- `reports/playwright-results/` — raw JSON/trace/screenshot artifacts from a Playwright run

None of this directory's generated content is committed (see the repo root `.gitignore`) -
it's regenerated by running the commands above, or downloaded as a workflow artifact from any
GitHub Actions run of `.github/workflows/qa-tests.yml` (uploaded even when tests fail). The
exact numbers from the run executed while building this project are captured as text in
`documentation/test-execution-report.md` instead of committing the binary report files.
